## Penjelasan

1. 01-week-1-mobile-development-ecosystem-flutter-refresh/

    Folder ini berisi seluruh hasil praktikum pada Week 1, yaitu materi
    mengenai mobile development ecosystem dan Flutter refresh.

2. README.md berisi penjelasan dan informasi mengenai praktikum Week


3. lib/ berisi source code aplikasi Flutter yang dibuat selama praktikum.

4. test/ berisi file untuk melakukan testing pada aplikasi.

5. screenshots/ berisi gambar atau screenshot hasil praktikum.


## reflections.md

    File reflections.md berada di folder reflections/ yang ada dalam folder screenshots/ pada setiap
    praktikum.

    File ini digunakan untuk menuliskan refleksi dari setiap tugas yang
    dikerjakan. Isi refleksi dapat berupa jawaban atas pertanyaan refleksi
    yang diberikan pada praktikum, pengalaman selama mengerjakan tugas,
    kesulitan yang ditemukan, serta hal baru yang dipelajari.

    Dengan adanya reflections.md, hasil praktikum tidak hanya berisi
    source code dan screenshot, tetapi juga menunjukkan pemahaman dan proses
    belajar selama mengerjakan setiap tugas.
